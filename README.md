# AI Customer Support Chatbot for Small Businesses

A full-stack AI-powered customer support chatbot built using Python, Flask, SQLite, HTML, CSS and JavaScript.

## Features
- Customer Registration and Login
- AI Customer Support Chat
- Gemini API Integration
- FAQ Knowledge Base
- Conversation History
- Admin Dashboard
- Customer Feedback

## Technology Stack
- Python
- Flask
- SQLite
- Google Gemini API
- HTML, CSS, JavaScript

## Run Locally
1. Install Python.
2. Install requirements:
   pip install -r requirements.txt
3. Run:
   python app.py
4. Open http://127.0.0.1:5000
